IN EVERYDAY TERMS

Imagine ten drivers heading to the same shop — and each one buys the same paper map, then buys it again and again along the way.

That is what the page was doing: paying for the same directions over and over, and stacking every copy on the screen.

01 — CONTEXT

A map that never stopped asking

An older system follows fertilizer trucks as they travel by road. Its map shows every truck and the route it is driving, and it updates on a regular schedule.

To draw each route, the page asked Google Maps for directions — and Google charges for every request. It actually asked twice per truck: once for the planned route from warehouse to destination, and once for a route from wherever the truck was right now to its destination.

And it did this for every truck, at every update. Ten trucks on the same road meant twenty requests, and a pile of identical lines drawn on top of each other.

02 — THE PROBLEM

Two problems, one cause

FOR USERS

A slow page

Every repeated route was one more line for the page to draw. The more trucks on the road, the heavier and slower the map became.

FOR THE BUDGET

A growing bill

Because the page kept asking, the cost grew with every truck and every update — not with the number of roads that actually existed.

03 — FIRST FIX · 2024–2025

Ask once, for the route that doesn’t move — then remember it

Two changes, made together: drop the request that could never be reused, and keep the one that could.

BEFORE · 2 REQUESTS PER TRUCK
Warehouse → destination. The planned route. Never changes. Truck → destination. Changes every time the truck moves, so it had to be bought again and again.
AFTER · 1 REQUEST, KEPT FOR LATER
Only the planned route is requested, and the page remembers it for later updates. Bonus: with every truck drawn against its planned route, one that strays far off course is easy to spot.

04 — SECOND FIX · 2026

Remember it for a month, not just a visit

The first fix had a catch: its memory was wiped whenever someone opened or reloaded the page, so every route was requested again. The second fix saves each route for 30 days.

01 — CONTEXT

Every trip has a start line and a finish line

This happens inside Truck Tracking, the same system behind the Route API cost story. Each delivery trip has an official starting point — the warehouse — and an official destination.

The driver presses start when the trip begins and finish when it ends. Those two taps are what the rest of the system trusts.

02 — THE LOOPHOLE

Nothing checked where those taps happened

START

Start the trip from anywhere

A trip could be started wherever the phone happened to be — far from the warehouse, even on a different island.

FINISH

Finish the trip from anywhere

The same at the other end: a delivery could be marked complete without ever reaching its destination.

For a dishonest driver, that was an open door. For everyone else, it meant the delivery records couldn’t prove what really happened.

03 — THE FIX

Put a fence around the start and the finish

A geofence is an invisible circle around a place. When the driver presses start or finish, the app checks whether they are inside it.

INSIDE THE ZONE

The trip starts — or finishes — as normal

Nothing changes for a driver who is where they should be.

OUTSIDE THE ZONE

The tap doesn’t count

Starting from another town, or finishing short of the destination, is no longer possible.

04 — THE TWIST

One circle size can’t fit every place

A fixed radius would either let cheaters through or lock honest drivers out. Two things make every location different.

SIZE

Places come in different sizes

A large start or finish area needs a bigger circle than a compact one, or drivers standing on site would be told they’re outside.

SIGNAL

Some places barely have signal

In rural areas and internet blank spots, a phone’s location is harder to pin down. Those places need extra room.

MAIN SYSTEM · GEOFENCE SETTINGS · ILLUSTRATION

SO THE RADIUS BECAME A SETTING

Central staff set the right radius for each location, straight from the main system.

The fence stays tight where it can and loosens only where the place — or the signal — demands it.

05 — OUTCOME

Start and finish mean something again

Less room for fraud

Starting from another island, or finishing short of the destination, no longer works.

Delivery data that holds up

Every recorded start and finish is tied to the place it was supposed to happen.
